# Farida Board

Social media posts ka plan banane wala aasan planner. Instagram, YouTube, TikTok aur Facebook ki posts ek jagah likh kar rakhein, aur dekhein ke kaunsi post kab daalni hai.

> Dhyan dein: ye tool khud post nahi karta. Ye sirf planning ke liye hai. Post aap ko khud app mein karni hogi.

## Kaise kholein

1. `post-planner.html` file ko apne phone ya laptop mein save karein.
2. File par double-click karein, ya browser (Chrome, Edge, Safari) mein kholein.
3. Internet ki zaroorat nahi hai.

## Naya post kaise add karein

1. **Platform** chunein (Instagram, YouTube, TikTok ya Facebook).
2. **Idea** likhein, jaise "Exam tips".
3. **Caption** likhein. Neeche characters ki ginti dikhti hai, aur limit se zyada hone par laal ho jati hai.
4. **Hashtags** likhein. Sirf lafz likh dein, `#` khud lag jata hai.
5. **Date and time** chunein. "Today 7 pm", "Tomorrow 7 pm" ya "Next week" se jaldi set ho jata hai.
6. **Add to board** dabayein.

## Board ko kaise samjhein

- **Week:** 7 din ke dibbe (Mon se Sun). Har post apne din mein nazar aati hai.
- **‹ Today ›:** pichla hafta, aaj ka hafta ya agla hafta dekhne ke liye.
- **List:** saari posts date ke hisaab se ek saath.
- **Filter:** sirf ek platform ki posts dekhne ke liye.

## Post ke card par kya hota hai

| Cheez | Matlab |
| --- | --- |
| Rang ki patti | Platform: Instagram gulabi, YouTube laal, TikTok sabz-neela, Facebook neela |
| **Idea** (grey) | Sirf khayal hai, abhi tayyar nahi |
| **Ready** (orange) | Sab tayyar hai, bas post karni hai |
| **Posted** (green) | Post ho chuki hai |
| Countdown | "In 3h" matlab 3 ghante baad. "Overdue" matlab waqt guzar gaya |
| **Copy** | Caption aur hashtags copy hote hain |
| **Edit** | Post mein tabdeeli karne ke liye |
| **Delete** | Pehli bar dabane par "Sure?" aata hai, dobara dabane par post hat jati hai |

Status badalne ke liye badge par click karein: Idea, phir Ready, phir Posted.

## Roz ka tareeqa

1. Idea likh kar post add karein.
2. Caption tayyar hone par status **Ready** karein.
3. Waqt par **Copy** dabayein aur app mein paste karke post karein.
4. Phir status **Posted** kar dein.

## Backup (bohot zaroori)

Aap ka data sirf usi browser mein save hota hai. Browser ka data clear karne ya phone badalne par posts chali jati hain. Is liye kabhi kabhi backup le lein.

- **Save backup:** saari posts ki ek `.json` file save hoti hai.
- **Load backup:** wahi file wapas chun kar posts wapas la sakti hain. Pehle se maujood posts dobara nahi judti.

## Yaad rakhein

- Phone aur laptop ka data alag alag hota hai.
- Ye tool reminder ya notification nahi bhejta.
- Is mein login ya account nahi hai.
